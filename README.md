# pcpp-labs

Repo with references and implementation of labs from [Python Institute PCPP-1 courses](https://pythoninstitute.org/pcpp1).

PCPP-1 (Certified Professional Python Programmer Level 1) is a Python certification issued by Python Insitute. This certification assets advanced features of the Python programming language.

It covers file processing work with builtin libraries as csv, xml and more, desktop interface programming with tkinter, network-programming with socket and OOP programming.

## pcpp-1-file-processing
Labs related to use of builtin libraries as csv, sml, logging, sqlite3 and configparser.


## pcpp-1-gui-programming
Labs related to use of tkinter builtin library.

## pcpp-1-network-programming
Labs related to use of json, xml syntaxes. It also covers socket and requests libraries use.
